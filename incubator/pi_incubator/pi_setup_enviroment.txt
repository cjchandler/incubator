Enable I2C Bus 6
Open the configuration file in a terminal using a text editor like nano: sudo nano /boot/firmware/config.txt 
Make sure the main ARM I2C interface is enabled by adding or uncommenting:dtparam=i2c_arm=on
Add the specific overlay for bus 6 on a new line:dtoverlay=i2c6
Save the file and exit the editor (press Ctrl+O, Enter, then Ctrl+X).
Restart your Raspberry Pi to apply the changes: sudo reboot.
